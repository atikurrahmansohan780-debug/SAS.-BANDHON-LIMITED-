অর্জন গুড়া মসলা - Android Studio Project

এটি Android WebView অ্যাপের সোর্স প্রজেক্ট; APK ফাইল নয়।

APK বানানোর নিয়ম:
1. কম্পিউটারে Android Studio ইনস্টল করুন।
2. Android Studio > Open দিয়ে এই ZIP Extract করা ফোল্ডারটি খুলুন।
3. Gradle Sync শেষ হলে Build > Build Bundle(s) / APK(s) > Build APK(s) চাপুন।
4. app/build/outputs/apk/debug/app-debug.apk ফাইলটি ফোনে পাঠিয়ে Install করুন।

দ্রষ্টব্য:
- ফোনে সরাসরি ইনস্টল করার APK এই প্যাকেজে নেই।
- Android Studio ও Android SDK-সহ কম্পিউটার প্রয়োজন।
